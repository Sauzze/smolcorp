# Example brief: a docs task

**Role:** docs · **Model:** Sonnet · **Folder:** a worktree of `shop`, branch `docs/setup-guide`

## The job
Write `docs/setup.md`: how a new developer gets the shop running locally, from a clean computer to a working cart page. Use what the repo already says (README, scripts, the `package.json`), and test every step yourself.

## Done means
- The guide is short (under two pages) and every command in it was run by you.
- A reader who has never seen the project can follow it with no other help.
- Plain, natural English, no jargon without a word of explanation.

## Off-limits
- Edit only `docs/`; if the code is wrong, write it in `STATUS.md` and leave it.
- Don't invent a step you didn't run. If one can't be checked, say "not checked" in the guide.
- No keys or real values: use `YOUR_KEY_HERE`.

## Proof I want
The list of commands you ran with the result of each, and the commit hash.
