    Use from anywhere (Tailscale)

    Over HTTPS the phone's own mic works too (iPhones only allow it there), and the deck reaches this computer from anywhere, but only from your own devices.

    1. Install Tailscale on this computer and on the phone, and sign in to both with the same account.
    2. In Tailscale's admin console, under DNS, check that MagicDNS and HTTPS Certificates are on.
    3. In Terminal on this computer, run:
      tailscale serve --bg --https=443 http://127.0.0.1:7710
    4. On the phone, open https://<this-mac>.<your-tailnet>.ts.net and pair with a code, as usual.

    or scan to pair over Tailscale

    Only devices in your tailnet can reach it, and they still need a pairing code. Don't use Funnel: that would put the deck on the public internet. To stop serving: tailscale serve --https=443 off.

    Turn on summaries?

    When you tap ✨ summary on an agent's desk, Smolcorp sends the end of that agent's Claude Code transcript to Anthropic's API: your recent requests and its replies, each cut short; the tools it ran; and the first line of each tool's output (for a file it read, that's the file's first line). Lines that look like secrets are taken out first. The project's folder name goes with it.

    • It uses your own API key (), and Anthropic bills it to you.
    • The model is Claude Haiku 5.5.
    • Nothing is sent until you tap ✨ summary, and you can turn this off here at any time.
